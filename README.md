# Project 009: Count Characters in a String

## Description
This project asks the user to enter a string and then counts the number of characters inside it.  
It helps beginners understand how strings work and how to use the built-in `len()` function.

## Skills Learned
- Working with strings  
- Using `len()` to count characters  
- User input  
- Basic printing  

## How to Run
1. Open `count_characters.ipynb` in Jupyter Notebook.
2. Run all cells.
3. Enter any text, and the program will show the number of characters.
